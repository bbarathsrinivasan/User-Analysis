# User Segmentation Summary

This file summarizes user segments based on `cumulative_total_value_max`.

## Segment Definitions

- **Large User**: `cumulative_total_value_max` ≥ 1,000,000
- **Medium User**: 10,000 ≤ `cumulative_total_value_max` < 1,000,000
- **Small User**: All remaining users
