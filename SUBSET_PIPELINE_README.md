# Subset Pipeline Documentation

## Overview

This document describes the subset pipeline that processes only complete markets, excluding events with incomplete data.

## Files Created

### 1. `subset_pipeline.py`
- **Purpose**: Processes trade data for complete markets only
- **Excluded Events**:
  - `arizona-senate-election-margin-of-victory`
  - `next-senate-majority-leader`
- **Output Directory**: `subset_all_markets_output/` (instead of `all_markets_output/`)
- **Functionality**: 
  - Discovers all events in the `raw/` directory
  - Filters out excluded events
  - Processes all markets in remaining events
  - Generates aggregated outputs in `subset_all_markets_output/`

### 2. `analyze_subset_users.py`
- **Purpose**: Analyzes users from the subset data
- **Input**: `subset_all_markets_output/` directory
- **Output**: `subset_all_users_analysis.csv`
- **Functionality**: 
  - Reads `date_group_token.csv` files from `subset_all_markets_output/user_*/`
  - Calculates statistics for each user
  - Generates `subset_all_users_analysis.csv` with 42 statistics per user

## Usage

### Step 1: Run the Subset Pipeline
```bash
python subset_pipeline.py
```

This will:
- Process all events except the excluded ones
- Generate outputs in `subset_all_markets_output/`
- Create the same file structure as `all_markets_output/`:
  - `user_<user_id>/yes_token.csv`
  - `user_<user_id>/no_token.csv`
  - `user_<user_id>/combined_token.csv`
  - `user_<user_id>/date_group_token.csv`

### Step 2: Analyze Subset Users
```bash
python analyze_subset_users.py
```

This will:
- Read all `date_group_token.csv` files from `subset_all_markets_output/`
- Calculate statistics for each user
- Generate `subset_all_users_analysis.csv`

## Output Structure

```
subset_all_markets_output/
├── user_<user_id_1>/
│   ├── yes_token.csv
│   ├── no_token.csv
│   ├── combined_token.csv
│   └── date_group_token.csv
├── user_<user_id_2>/
│   └── ...
└── ...

subset_all_users_analysis.csv  (generated by analyze_subset_users.py)
```

## Key Differences from Main Pipeline

1. **Excluded Events**: Two events are excluded due to incomplete data
2. **Output Directory**: Uses `subset_all_markets_output/` instead of `all_markets_output/`
3. **Analysis File**: Generates `subset_all_users_analysis.csv` instead of `all_users_analysis.csv`

## Important Notes

- **Original Data Unchanged**: The original `all_markets_output/` and `all_users_analysis.csv` remain unchanged
- **Per-Market Outputs**: Per-market outputs still go to `output/` directory (unchanged)
- **Only Aggregated Outputs**: Only the aggregated all-markets outputs go to `subset_all_markets_output/`

## Verification

To verify the subset pipeline is working correctly:

1. Check that excluded events are not processed:
   ```bash
   grep -r "arizona-senate-election-margin-of-victory" subset_all_markets_output/
   grep -r "next-senate-majority-leader" subset_all_markets_output/
   ```
   (Should return no results)

2. Compare user counts:
   ```python
   import pandas as pd
   df_all = pd.read_csv('all_users_analysis.csv')
   df_subset = pd.read_csv('subset_all_users_analysis.csv')
   print(f"All users: {len(df_all)}")
   print(f"Subset users: {len(df_subset)}")
   ```

3. Verify output structure matches:
   ```bash
   ls -la subset_all_markets_output/user_*/date_group_token.csv | head -5
   ```
